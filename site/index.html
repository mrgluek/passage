You shall pass.Ты пройдёшь.

A local SOCKS5 proxy for messaging apps on Android, Windows, Linux and macOS. Apps connect to it on 127.0.0.1, and Passage picks the best available connection for them automatically. Android, Windows 10+ and macOS 13+ have an app; Linux, macOS and Windows can run it as passage-cli.

Локальный SOCKS5-прокси для мессенджеров на Android, Windows, Linux и macOS. Приложения подключаются к нему на 127.0.0.1, а Passage сам выбирает для них лучшее доступное соединение. Для Android, Windows 10+ и macOS 13+ есть приложение; на Linux, macOS и Windows можно запустить passage-cli.

Windows 10 or later: unpack the archive and run passage.exe, nothing else to install. It stays in the notification area when its window is closed. Settings (passage.ini) and the link (link.txt) are kept in the same folder; put a new link.txt there to update the link.

Windows 10 и новее: распакуйте архив и запустите passage.exe, ничего доустанавливать не нужно. Когда окно закрыто, он остаётся в области уведомлений. Настройки (passage.ini) и ссылка (link.txt) хранятся в той же папке; чтобы обновить ссылку, положите туда новый link.txt.

macOS 13 or later: unpack the ZIP, move Passage.app to Applications and open it. Closing the window keeps Passage in the menu bar. Settings can enable launch at login. Open a received link and choose Open in Passage to import it.

macOS 13 и новее: распакуйте ZIP, перенесите Passage.app в «Программы» и откройте его. После закрытия окна Passage остаётся в строке меню. В настройках можно включить автозапуск. Откройте полученную ссылку и нажмите Открыть в Passage, чтобы импортировать её.

The macOS app has no Apple Developer ID signature and is not notarized. If macOS blocks the first launch, try opening it, then choose System Settings → Privacy & Security → Open Anyway. Alternatively, remove quarantine from this app in Terminal:

У приложения для macOS нет подписи Apple Developer ID и нотариализации. Если macOS не даёт запустить его, попробуйте открыть приложение, затем выберите Системные настройки → Конфиденциальность и безопасность → Всё равно открыть. Другой способ — снять карантин с этого приложения в Терминале:

xattr -dr com.apple.quarantine /Applications/Passage.app
open /Applications/Passage.app

Adjust the path if you installed it elsewhere. This only removes quarantine from Passage; it does not disable Gatekeeper.

Если приложение установлено в другой папке, измените путь. Команда снимает карантин только с Passage и не отключает Gatekeeper.

UsageКак пользоваться

  1. Open the passage:// link you received, or paste it in Settings, and tap the start button. Allow notifications and running in the background.
  2. Tap Copy proxy link and paste it into the proxy settings of the other app, or tap Open proxy link if the app adds proxies from links.
  1. Откройте полученную ссылку passage:// или вставьте её в настройках и нажмите кнопку запуска. Разрешите уведомления и работу в фоне.
  2. Нажмите Скопировать ссылку на прокси и вставьте её в настройки прокси другого приложения или нажмите Открыть ссылку на прокси, если приложение добавляет прокси по ссылке.

Connection linksСсылки подключения

Since 0.3.0, one link can include several routes in priority order. A later link can add routes or replace the saved set: Passage shows the action and asks for confirmation. Earlier links still work.

Начиная с 0.3.0, одна ссылка может содержать несколько маршрутов с приоритетами. Следующая ссылка может добавить маршруты или заменить сохранённый набор: Passage покажет действие и запросит подтверждение. Старые ссылки продолжают работать.

Since 0.7.0, a link can be a subscription: besides routes (or instead of them) it carries an address from which Passage keeps the routes up to date by itself.

Начиная с 0.7.0, ссылка может быть подпиской: кроме маршрутов (или вместо них) она содержит адрес, по которому Passage сам обновляет маршруты.
